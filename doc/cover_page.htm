Directions to access product or any other additional information

The product has three components. Start the Rust backend first: cd Product/server && cargo run --bin demo_seed && cargo run. Then launch the React admin panel in another terminal: cd Product/admin && bun install && bun dev, and open the printed URL in any modern browser. The iPad app is opened with Product/swiftui/together.xcodeproj in Xcode 15+ and run against an iPad Pro simulator in landscape.
